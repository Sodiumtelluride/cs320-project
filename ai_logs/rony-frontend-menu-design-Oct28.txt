How the new menus work

Opening a location causes the browser to request its menu using the location identifier, selected date, and menu section.

Currently, the included server endpoints answer those requests with an empty food list. The interface therefore displays “Menu information is not available yet,” while the controls continue working.

The existing NEXT_PUBLIC_MENU_API_BASE_URL configuration selects the actual backend service. Once that service returns compatible records, the same components display the foods, prices, tags, and food-detail information. The backend team must confirm or map the documented location identifiers and response fields.
