Worcester’s menu, with all four location blocks available.

Clicking a location follows this sequence:
	1	Its card opens a URL containing the hall’s identifier.
	2	The menu route reads that identifier and initializes the menu.
	3	The data source requests the selected hall’s menu.
	4	Clicking a food requests its detailed information.
Changing the hall, date, or meal also updates the URL. For example:
/menus?hall=hampshire&date=2026-10-21&meal=dinner
Refreshing that address preserves the selection.

The location-card component accepts props, meaning inputs supplied by its parent:
	•	diningHalls: the locations to display.
	•	selectedHallId: the currently selected location.
	•	onSelect: the function to run when a selection block is clicked.
	•	compact: whether to use the smaller menu-page layout.
On the landing page, cards are navigation links. Inside the menu browser, they are buttons that change the selected hall.
